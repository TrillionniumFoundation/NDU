# Developmental measurements, not preregistration

R19 is a developmental revision. Its retrospective R16 reanalysis is distinct from the new follow-up timing and deliberate theorem checks. A local timing pilot initially shared the previous-iterate workspace between two target tolerances. That could give the second target an uncharged within-context warm start. The implementation was corrected to use separate workspaces, and every primary timing observation was regenerated. No model, seed, threshold, context count, or selection rule changed. The published primary timing records use only the corrected implementation. The final GitHub reproduction regenerates these records on its own host; local development timing numbers are not substituted for that run. This correction is disclosed rather than presented as an immutable preregistered design.
