\subsection{New piecewise, circuit, and full-parametric checks}\label{sec:r33-evidence}
The additional reference implementation uses exact rational arithmetic throughout. Its local optimizer enumerates and compares the maximizing candidate in each quadratic piece; this direct check is separate from the local inverse-marginal response constructor. Twenty-four seeded five-vertex recombining DAGs include differentiable joins, strict marginal jumps, rational caps, and discounting. At all generated event points, intervening prices, and tail probes, 4,170 local optimality comparisons and 834 whole-graph circuit comparisons succeed. The same run verifies 834 circuit root inversions and 836 primal--dual certificates, including fixed-tier and minimum-cap cases. These are finite exact checks of the implementation, not substitutes for the proofs in Section~\ref{sec:r33-extension}.

The parametric reference uses a different mathematical representation: it explicitly unfolds small quadratic problems, enumerates independent active constraint sets, solves the associated rational KKT systems as affine functions of price, and derives the validity interval of each candidate region. It compares coefficients on every open interval of the union of the resulting breakpoints, and also compares boundary values. Each of four three-vertex instances examines 130 candidate active sets; their complete feasible parametric paths have five, three, four, and five regions. All four paths agree exactly with the compact compiler. This is stronger than testing a collection of root promises, but it remains an exhaustive small-instance reference, not a scalable parametric-flow implementation.

The analytic chain is also replayed for sizes two through 128 by powers of two. At the largest size there are 256 global knots and 16,640 explicitly stored response segments. The shared representation instead retains 128 graph nodes and 384 local response segments, together with edges and the event list. The count compares representations of the same function family, not different optima. The reported shared size is persistent post-compilation storage; the test does not claim linear peak preprocessing memory.

Finally, exact partition enumeration returns the deterministic two-symbol loss $1/8$ in Proposition~\ref{prop:r33-random-gap}, and the endpoint lottery returns $1/96$. A rational codebook grid is retained as a regression test only; the global two-symbol optimum follows from the proposition's piecewise analytic proof. The electronic companion and machine-readable record identify these new checks separately from all inherited experiments.
