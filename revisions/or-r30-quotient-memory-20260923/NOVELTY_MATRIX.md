# Claim-by-claim positioning for R30

| Result | Established/inherited component | What R30 proves or changes | Boundary |
|---|---|---|---|
| Laminar map, Proposition 2.1 | Classical tree resource allocation, Mjelde (1983), Tang (1990) | Explicit probability-weighted invertible mapping of objective, boxes, caps and root equality | No claim to originate this feasible-set class |
| Polymatroid rank, EC.1 | Polymatroid allocation lineage | Self-contained lower-bound translation and truncated-base representation for this model | A clarified classical connection, not a claimed new polymatroid theorem |
| Occurrence quotient, Theorem 3.1 | R29 finite response recursion; classical subtree marginal reduction | Formal suffix-history bijection and normalized response equality | Memoizing normalized classical responses gives the same recursion |
| Response size | R29 cap/clipping closure | Explicit compact input/output accounting and coefficient-event construction | Global knots O(N) but total response tables O(N²) |
| Rational preprocessing, Theorem 3.3 | Rational arithmetic and acyclic path expansion | Primitive-denominator argument; polynomial coefficient heights and bit operations | Not strongly polynomial; aggregate certificate heights are separately bounded |
| Minimal machine, Theorem 4.1 | Running-max price policy; standard behavioral minimization principle | Exact smallest writable alphabet for reached price behaviors, contiguity, constructive implementation; randomized exact-optimum necessity | Fixed root query; explicit public/read-only/writable architecture; not all randomized restricted values |
| Heterogeneous frontier, Theorem 4.2 | R29 equal-probability quadratic renewal example; standard ordered segmentation | Unequal probabilities, increasing concave terminal rewards, heterogeneous convex costs, contiguity proof | Deterministic encodings; exact family-specific value formula |
| Outside-option dispersion, Proposition 4.3 | Renewal construction | Strict loss increase for insufficient memory at fixed public process and mean payment; exact alphabet jump | Specified mean-preserving dispersion path, not every possible dispersion order |
| Zero-release table, Proposition 5.1 | R29 graph QP and ordinary convex programming | Supporting comparator with clean notation and globally shared design | Not the main algorithmic novelty |
| Fixed-release cut, Proposition 5.2 | R29 finite-price oracle; ordinary dual sensitivity | Complete split at physical/corridor ties and singleton intervals; exact tests | No finite exact outer Benders cut bound |
| Experiments | R29 exact audits | Independent occurrence reduction, sparse generic QP, public-graph primal grid, larger and breakpoint-dense scale families | No universal fastest-method, original-author-code or SDDP speed claim |
| Broader accepted-service theory | R1–R29 switching, sensitivity, continuity, cache and governance results | Retained in complete readable/source volumes and provenance map | Those results keep their own assumptions; not all covered by finite-price theorem |

The theorem package is presented affirmatively for mathematical review. The accessible literature supports the above structural distinctions; it does not certify exhaustive historical priority or the strongest algorithm known under every tree/laminar input model.
