This computational supplement preserves every earlier empirical table and

All predecessor formal statements and proofs remain in the main manuscript or

\subsection{Interior-model comparator brackets}
The coefficient seed is 2402301. For every original context and radius, two
three-coordinate integer vectors are sampled uniformly from minus seven through
seven and divided by eight. Every vector is strictly interior to the cube.
Both comparators use the true interior reward and friction. The true restricted
class uses that model's own participation and capacity coefficients; the outer
class is exactly the original analytically containing class. Both retain root,
box, and time-only amendment restrictions.

Each solver supplies a proposal and dual prices. A separate rational procedure
rounds date/service amplitudes, reconstructs root payments, and mixes within the
time-only subspace toward a strict accepted anchor. A general rational Fenchel
calculation then checks the two comparator intervals without trusting solver
status or its printed objective. Negative controls perturb root payment,
time-only equality, inequality prices, switching tensions, and interpolation
weights. The records include each rational implementation and all dual prices.
The mean, median, quartiles, ninety-fifth percentile, and maximum of total,
outer-set, and interpolation slack are retained at every radius. This is a
sensitivity diagnostic, not a statistically calibrated uncertainty model.

\subsection{Timing, training, and memory accounting}
Training seeds are 2402401 through 2402403; test seeds are 2403401 through
2403403. Each configuration has one fixed fit and a fresh held-out sample.
The predictors retain the earlier 192-feature tanh-gradient construction and
cubic radial-basis direct-price construction. Audited optimizer-generated labels contain
both the optimized value and its resource statistic; they are not information
learned without an optimizer. The entire label generation, including the
teacher workspace and rational audit, is charged to either learned method.
Shared labels are not charged twice when the two methods are jointly fitted,
but a standalone deployment of either method carries the full label bill.

A setup timer includes sparse matrix construction and workspace initialization.
Online timers include every candidate-specific operation, including numerical
repair and exact checking. Method order is independently randomized within a
context. The classical comparator retains both primal and dual continuation
state along the same ordered context sequence; each new repetition resets that
sequence. No method is allowed to use another method's fallback state. When
fallback occurs it starts in a new lifted workspace. Consequently the cost
record directly distinguishes proposal overhead from fallback avoidance and
from hypothetical warm-start savings not implemented here.

A context is the resampling unit for paired intervals. Its three timings are
averaged first, and the 32 context-level paired savings are then resampled
10,000 times with seed 2405401. These exploratory percentile intervals concern
fixed fitted policies on the declared context distribution. Repetition does
not turn 32 contexts into 96 independent training/deployment experiments.
The retrospective R22 scaling reanalysis has only eight context-level pairs
per configuration and is labeled accordingly.

Memory statistics distinguish serialized predictor bytes, reachable NumPy
array storage, and sparse input-matrix bytes. Array views may share backing
storage; sparse matrix counts exclude factorization workspace. Peak resident
memory is a whole-process high-water mark, not a per-method peak. These
quantities are reported with their scopes rather than summed into an
unsupported total-memory comparison.

\subsection{Recorded robust certification cost}
The original robust run stores each method's optimization, rational repair,
and vertex-evaluation time and the shared eight-comparator batch time. The
retrospective analysis adds that entire batch to each method when interpreting
it as an independently certified decision. It also reports the batch
separately so that actual reuse across candidate methods is visible. Original
ensemble prediction occurred before those timers; no new-machine measurement
is spliced into the archived totals. The resulting archived sum is a disclosed
lower bound on full learned end-to-end time, not evidence for acceleration.
A pointwise gain certificate is an operationally more expensive object than a
feasible proposal or a certificate used only in offline evaluation.



The fresh robust-cost check uses seed 2407401, sixteen contexts, and radii zero
and one quarter. Ensemble prediction is timed on each query rather than
precomputed outside the timer. Each of the eight comparator solves uses a
fresh workspace and an independent rational upper certificate. Candidate
ordering rotates by context. Model deserialization and geometry construction
are one-time costs and are reported separately. These measurements are made
sequentially after the nominal matched study, on the same execution host;
they are not added to the historical R23 machine times. All rational records
are independently replayed.
