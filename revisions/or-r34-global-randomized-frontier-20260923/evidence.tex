\subsection{Global continuous-codebook and institutional checks}\label{sec:r34-evidence}
The additional experiments test the global optimization object in Theorem~\ref{thm:r34-global}, not only optimal encoding for a fixed codebook. On 51 exact small instances, the dynamic program agrees with a separately coded exhaustive comparator over all cap-anchored prefixes and analytically minimized terminal intervals. That comparator uses direct branch losses and interpolation of each quadratic, not the production prefix moments. It performs 1,932 candidate comparisons and obtains 446 exact frontier equalities across the randomized and deterministic problems. Another 1,073 direct comparisons use grids containing noncap codewords. Grid agreement is a falsification check; the structural theorem supplies continuous globality.

Independent replay checks 255 expected-participation controllers, including all budgets through eight on four larger inputs. Every branch cap and root promise is verified with zero rational residual. The replay flags individual draws that exceed their branch cap, rather than treating an expectation certificate as a pathwise certificate. Deterministic controllers are separately replayed and realize the pathwise frontier. Table~\ref{tab:r34-frontiers} gives the two exact three-branch examples. The heterogeneous example is particularly diagnostic: its optimal final level is not a cap, and a cap-only optimizer returns a strictly larger loss.

The synthetic scale family uses 16--128 branches, positive heterogeneous probabilities, and intermediate costs that include zero curvature. Computing all eight budgets uses the same recurrence; exact output coefficients in this run require at most 29 bits. Timings, complete rational losses, seeds, input conventions, and runtime metadata accompany the source. These tests extend the retained complete-parametric-path checks to a distinct continuous-codebook design problem. They do not report a run of a published specialized parametric solver or establish empirical calibration of service demand.
