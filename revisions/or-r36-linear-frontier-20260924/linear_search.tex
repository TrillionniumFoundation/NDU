\subsection{A linear-work implementation of both frontiers}\label{sec:r36-linear}
Monotone row minima alone do not justify linear matrix search: the property must hold in every submatrix, including those with no feasible entry in a row. We now supply that interface for the contractual costs. The search algorithm is the classical SMAWK method of \citet{AggarwalEtAl1987}; the construction below establishes its applicability, not a new general matrix-search principle.

\begin{theorem}[Linear-work contractual frontiers]\label{thm:r36-linear}
Under \eqref{eq:r34-primitives}, with ordered rational inputs and $1\leq m\leq k$, the complete expected-participation and deterministic/pathwise frontiers through budget $m$, together with one optimal codebook per budget, can each be computed in $O(mk)$ exact rational operations and comparisons and $O(mk+k)$ stored scalars and indices. With the coefficient height $S$ of Theorem~\ref{thm:r34-global}, a conservative bit bound is $O(mkS^3)$. The highest randomized level is optimized over its continuous interval, not restricted to a grid or to the caps.
\end{theorem}
\begin{proof}
Give a feasible entry in column $c$ the lexicographic key $(0,A_{rc},c)$, so finite ties go left. For the terminal array, give an infeasible prefix entry $c<r$ the key $(1,0,-c)$; for a prefix-program row, give an infeasible suffix entry the key $(1,0,c)$. All feasible keys precede every infeasible key. Discard globally unreachable predecessor columns before completing a program layer.

These completed matrices are totally monotone. Indeed, for $r<s$ and $c<d$, strict preference for $d$ over $c$ in row $r$ persists in row $s$. When all four entries are feasible, Theorem~\ref{thm:r35-monge} implies this assertion; adding the preceding value function to each column preserves the inequality. In the terminal staircase, later rows can lose feasible columns only from the left. If both compared entries become infeasible, the negative column index continues to prefer $d$. In a program layer, feasible prefixes expand with the row index: an earlier preference for $d$ requires both compared columns to be feasible, so both remain feasible. The argument applies to arbitrary submatrices, not only consecutive rows or columns.

SMAWK therefore finds all terminal minima and each program layer in $O(k)$ key comparisons. Each finite key uses the constant-work exact moment oracle; padded keys never evaluate an economic cost. Scanning final-anchor candidates adds $O(mk)$ work. Reconstructing one winning codebook per budget adds $O(m^2)\leq O(mk)$. The search stores linear index lists, not a quadratic matrix; two value rows, terminal optima, and backpointers give the stated space. The arithmetic expressions are unchanged, so exact fraction reduction and comparison retain the stated coefficient-height and bit bounds. The companion records the reduction and interpolation invariants.\end{proof}

A uniform numerical infinity with ordinary leftmost ties is not a substitute for this completion. On the upper staircase, columns 1 and 2 can prefer 2 at row 2 but prefer 1 when both become infeasible at row 3. The ordinal completion resolves this submatrix obstruction without altering any feasible optimum. It improves the proved work bound, not the institution, the memory accounting, or the admissible cost class.
