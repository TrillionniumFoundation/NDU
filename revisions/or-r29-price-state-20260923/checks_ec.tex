\section{Finite-Price Experiments and Independent Checks}\label{ec:r29-checks}
\subsection{The exact design}
The production algorithm and its proofs appear in main Sections~\ref{sec:price}--\ref{sec:shared-new}. No smoothness assumption or approximation grid is used in these new experiments. The retained sections below give the complete derivations for the broader models in the print appendices; their earlier experimental records are not new R29 observations.

In a generated $T$-date graph with $S\in\{2,3\}$ regimes, the root is unique and each later layer has $S$ vertices. Hence $N=1+(T-1)S$. Every nonterminal regime connects to all regimes of the next layer. For current regime index $z$, successor index $j$, and seed $s$, the unnormalized probability is $1+((z+2j+s)\bmod3)$; divide by the sum over successors. Discounting is $19/20$. Using the standard-library pseudorandom generator with the declared seed, draw integer reward numerators from $\{-4,\ldots,44\}$ and divide by 20, curvature numerators from $\{8,\ldots,24\}$ and divide by 10, and payment numerators from $\{8,\ldots,16\}$ and divide by 10. The complete rational primitive instances are stored, so replay does not depend on redrawing them.

Let the date-specific reference tier be $c_t=(7+(t\bmod5))/20$. Compute its conditional payment $P_v$ backward. Compute the discounted annuity $A_v=1+(19/20)\sum_wp_{vw}A_w$. The cap is $B_v=P_v+((3v+s)\bmod7)A_v/100$. The exact root promise is $P_0$. The reference table is therefore feasible under every continuation cap. In the unrestricted cases the physical interval is $[0,1]$; in the fixed-table corridor cases it is $[c_t-1/4,c_t+1/4]$. These are two different declared feasible classes, not a claim that the fixed table has already been optimized. Optimized time-only comparisons use the unrestricted primitives and the exact condensed quadratic program in Proposition~\ref{prop:table-condensed}.

The main suite consists of the strict-memory example, seven boundary instances, twelve seeded small graphs, nine unrestricted horizon/state configurations, and six fixed-corridor configurations. Every stored instance includes its full primitive graph. The coefficient bit length in the timing record is the maximum numerator or denominator bit length among stored affine response coefficients. Serialized bytes include decimal encodings, not an idealized compressed-memory estimate. Peak resident memory is labeled as the whole sequential generator's peak; it is not represented as isolated configuration memory.

\subsection{Response verification is not a sampled feasibility test}
The checker does not import the price solver. At each vertex it forms the union of all submitted parent and child knots, both local tier knots, and the submitted cap threshold. Between consecutive points, both sides of the response identity are affine after also accounting for the cap threshold. Equality is checked at every knot, at an interior midpoint of every interval, and on both constant tails. The midpoint and tail checks also verify the reflected implementation and cap complementarity. The input lists must be strictly ordered, continuous at their knots, nonincreasing, and constant on their tails. Thus these exact rational checks certify the entire displayed functions, not only the root query.

A separate forward check reconstructs the discounted mass entering every public/price pair. It verifies local interval feasibility, the actual conditional payment recursion, each continuation cap, root equality, stationarity, sign restrictions, and complementarity. Finally it compares the total reward with main equation~\eqref{eq:price-dual}. The verifier rejects a missing child state or a mass mismatch. The certificate needs no claim that a floating-point optimizer has identified an exact active set.

The independent tree audit is deliberately different. It unfolds only the fourteen small test graphs, builds the conditional subtree-incidence matrix directly, and checks matrix KKT conditions on that extensive form using rational arithmetic. It then uses a feasibility linear program followed by SLSQP with target objective tolerance $10^{-12}$. The separate numerical comparison is accepted only with objective discrepancy below $10^{-7}$ and constraint violation below $10^{-8}$. Those thresholds do not relax the rational optimality certificate. No production complexity count includes a small-test tree as though it were required for execution.

For the optimized table comparison, a conventional primal active-set method supplies rational candidates. The second checker reconstructs reach weights, conditional payment coefficients, objective curvature, all cap rows, and the root row independently from the primitive graph. It verifies the exact primal--dual bracket rather than trusting the active-set iteration count. The shared-design cuts are checked at 54 joint perturbations of table entries and release; each queried value also has its own exact certificate. These are fixed-table oracle tests, not a numerical claim of finite convergence of a continuous outer master.

The two-service check uses discount one and a deterministic serial expansion of the two local coordinates. The extra intermediate cap is redundant. The transformation preserves the one scalar commitment and the original node's continuation cap; it does not split the problem into independently budgeted service blocks. The general vector-tier corollary is proved in the main paper, not inferred from this one check.

\subsection{Memory calculations and reproducibility}
In the strict-memory example, a public-only terminal tier $c$ satisfies $0\leq c\leq1/4$. Write the intermediate tiers as $y$ and $1-2c-y$. The cap in regime $A$ gives $0\leq y\leq1/4-c$. For fixed $c$, the derivative of reward with respect to $y$ is $1/2-c-y\geq1/4$, so the optimal $y$ is $1/4-c$. The resulting derivative with respect to $c$ is $5/2-2c>0$. Hence $c=1/4$, $y=0$, and the other tier is $1/2$. Direct substitution gives $13/32$, versus the finite-price optimum $27/32$. Their difference is $7/16$.

For the memory-frontier family, caps are $b_j=j/(k+1)$, with $k=2,3,4,5,6,8,16,32$. The checker verifies every dynamic-programming recurrence and the minimizing partition's reward. For $k\leq6$, it additionally enumerates all set partitions, including noncontiguous partitions, and compares their best costs with the ordered solution. Across those five sizes there are 277 partitions. This separates a proof of the ordered-cell reduction from a numerical search that presupposes it.

The scripts and immutable primitive/certificate records distinguish deterministic arithmetic from observed timing. Standard-library rational replay covers the production responses, memory frontier, shared-table certificates, and cut checks. Only the separate numerical tree experiment uses NumPy and SciPy. The build record gives software versions, command outputs, hashes, page counts, and the final source-preservation checks. The historical R24--R28 replays are run unchanged; their outputs are not merged into the new timing table.
